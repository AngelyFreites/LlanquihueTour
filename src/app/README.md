# Llanquihue Tour

## Descripción

Sistema orientado a objetos desarrollado en Java para representar personas vinculadas a una agencia de turismo.

## Estructura del proyecto

### Paquete model

- Direccion
- Persona
- GuiaTuristico

### Paquete app

- Main

## Conceptos aplicados

- Encapsulamiento
- Herencia
- Composición
- Constructores
- Getters y Setters
- Método toString()

## Ejecución

1. Abrir el proyecto en IntelliJ IDEA.
2. Ejecutar la clase Main ubicada en el paquete app.
3. Observar la información de los guías turísticos en la consola.
